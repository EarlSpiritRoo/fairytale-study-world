Optional sound files for Fablenook.

Everything you hear is synthesised in the browser, so this folder can stay empty.
To swap a synthesised sound for a real CC0 recording:

  1. Put the file here, for example audio/waterfall.mp3
  2. In config.js, list it:   AUDIO_FILES: { waterfall: "audio/waterfall.mp3" }

Names you can use (each replaces only that sound):
  skyfield     realm ambience: high wind and distant wings
  lagoon       realm ambience: muffled underwater hum
  hollyhollow  realm ambience: wind and snow
  pavilion     realm ambience: crickets and a breeze
  petalwood    realm ambience: birdsong and rustling leaves
  waterfall    positional: every waterfall in Skyfield
  fire         positional: the Hollyhollow library fireplace
  shore        positional: lake lapping around the Moonlit Pavilion shores
  bubbles      positional: bubble vents in the Coral Lagoon
  chimes       positional: soft chimes near the Petalwood fairies
  wings        positional: wings at the Skyfield pegasus stable

Seamless loops work best (mp3 or ogg). CC0 sources: freesound.org (filter by the
Creative Commons 0 licence), pixabay.com/sound-effects, opengameart.org.
